# etherdharmesh.github.io

Personal website for Ether Dharmesh — MD/PhD student, Immunology Graduate Group,
Perelman School of Medicine, University of Pennsylvania.

Static site, no build step: `index.html` plus `assets/`.
Type is Inter and Geist Mono, loaded from Google Fonts.
Paper figures in `assets/` are reproduced from CC BY open-access articles and
credited on the page.

Local preview:

    python3 -m http.server 8000

then open http://localhost:8000
